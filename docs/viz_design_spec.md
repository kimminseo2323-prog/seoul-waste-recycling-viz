## 섹션별 상세

### 1. 도입 — "직매립 금지, 서울의 쓰레기는 어디로?"
- KPI 카드 3개: 총 발생량(383만톤), 재활용률(39.3%), 매립률(5.6%)
- 2026.1.1 직매립 금지 시행 배경 텍스트
- fade-in 애니메이션

### 2. 현황 — Sankey Diagram
- 노드: 서울시 생활폐기물 → 재활용 / 음식물 / 소각 / 매립 / 기타
- 2024년 실데이터 기반
- 호버 시 톤 수 + 비율 툴팁
- 매립 경로에 빨간 점선 "직매립 금지!" 표시
- 연도 선택 드롭다운 (2020~2024 비교)

### 3. 문제 — 서울 자치구 Choropleth
- 서울 25개 자치구 지도
- 색상: 재활용률 낮음(빨강) → 높음(초록) 그라데이션
- 클릭 시 해당 구 상세 팝업 (발생량, 재활용률, 아파트비율)
- 연도 슬라이더 (2020~2024)

### 4. 원인 — 산점도
- X축: 아파트 비율(%)
- Y축: 재활용률(%)
- 버블 크기: 인구 수
- 버블 색상: 1인가구 비율
- 호버 시 자치구명 표시
- 회귀선 (상관관계 시각화)
- 인사이트 텍스트: "아파트 비율이 높을수록 재활용률이 높다"

### 5. 심화 — 강서구 Deep-dive
- 수평 바차트: 강서구 25개 행정동별 쓰레기 배출량
- 일반주택 vs 공동주택 분리
- 파이차트: 강서구 건물유형 비율
- 정렬 토글 (배출량순/행정동순)

### 6. 해결 — 클린하우스 제안
- 서울 지도 + 다세대 밀집도 히트맵 오버레이
- 제안 입지 마커 (재활용센터 위치 기반 Gap 분석)
- 마커 클릭 시 근거 팝업 (다세대 수, 1인가구 비율, 가장 가까운 기존 시설 거리)
- 커버리지 원 (반경 300m)
