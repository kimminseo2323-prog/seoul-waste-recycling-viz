### [문제] 3:10~4:35 — 어디가 문제인가
> "재활용률을 자치구별로 보면 2배 차이가 납니다. 관악구 54% vs 강서구 46% — 같은 서울인데 왜 이렇게 다를까요?"

### [심화] 6:05~7:25 — 구체적 사례

### [해결] 7:25~9:30 — 제안 (핵심!)

## 예상 질의 + 답변 준비

### Q1: "재활용률과 아파트 비율의 인과관계를 어떻게 증명하나요?"
> **A**: 상관분석(r=0.7+) + 매개변수 통제(인구밀도, 소득수준 보정 후에도 유의). 추가로 "인프라 유무"라는 메커니즘을 질적으로 설명 (아파트=분리배출함 의무, 다세대=없음). 인과 추론의 한계는 인정하되, 정책적 시사점은 충분.

### Q2: "클린하우스 설치 비용과 효과 근거는?"
> **A**: 서울시 자원순환과 자료 기준 1개소 약 2,000~3,000만원. 효과는 선행사례 — 서울 마포구 2023 시범사업에서 설치 후 해당 권역 재활용률 +18%p 상승. 보수적으로 +7%p 적용.

### Q3: "매립 금지된 쓰레기가 실제로 어디로 가고 있나요?"
> **A**: 2024년 데이터에서 "기타" 항목이 340,132톤(8.9%)으로 급증. 이는 시멘트 소성로, 타 시도 위탁소각 등으로 분산 처리 중. 장기적으로 재활용 전환이 유일한 해법.

### Q4: "50m 격자 단위 분석이라고 했는데, 실제로 그 정밀도가 필요한가요?"
> **A**: 클린하우스는 도보 5분(300m) 접근이 핵심. 자치구 단위로는 "어디에"를 결정할 수 없음. 격자/블록 단위 분석이 있어야 "이 골목의 이 자리"를 제안할 수 있음.

### Q5: "시각화 도구 선택 이유는? 왜 D3.js?"
> **A**: Sankey 다이어그램은 D3의 강점. Tableau/Power BI로는 Sankey 커스터마이징이 제한적. 또한 대회 요구사항인 "단일 HTML 제출"에 적합. 서버 불필요, 브라우저만으로 인터랙션 가능.

### Q6: "데이터 최신성 — 2024까지인데 2026 정책을 논할 수 있나요?"
> **A**: 2024 데이터가 현재 공개된 최신. 2026.1.1 직매립 금지 시행 후 "기타" 비중이 더 늘어날 것으로 예측 가능. 분석의 방향성은 최신 데이터로 더 강화됨.

### Q7: "강서구를 심화 사례로 고른 이유는?"
> **A**: (1) 발생량 서울 1위(59만톤 — 자원회수시설 때문), (2) 행정동 수 25개로 동별 차이 분석에 충분, (3) 다세대 밀집 동(화곡)과 아파트 단지(마곡/가양)가 공존 → 대조군 분석 용이.

## 디자인 가이드라인 (PPT 적용)

### 레이아웃 원칙
- **1장 1메시지**: 각 장에 하나의 핵심만
- **시각화 70% + 텍스트 30%**: 차트가 주역, 텍스트는 보조
- **좌→우, 상→하 시선 흐름**: 핵심 차트는 우측 또는 중앙 배치
- **여백 충분히**: 한지 배경의 여유로운 느낌 유지

- 재활용 = 초록(#43a047), 소각 = 노랑(#f9a825), 매립 = 빨강(#c62828)
- 모든 차트에서 동일 색상 코드 유지
- 강조 = 서울시 파랑(#1565c0)

- 제목: Noto Serif KR Bold 28pt
